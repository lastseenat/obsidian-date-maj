# Date de mise à jour

Pied de note daté, posé à la main :

```
🔄 Maj 17/10/2025 (GPT-5)
👁️ Lu 08/10/2026
```

- Trois boutons dans l'en-tête de chaque note : **Mise à jour**, **Lue partiellement**, **Lue**
- Le modèle ajouté à la date Maj se règle dans les paramètres du module
- Vue latérale **Par date** (icône horloge) : notes triées par date de mise à jour ou de lecture

## Installation avec BRAT

1. Installer BRAT dans le vault et y renseigner un jeton GitHub (dépôt privé)
2. Dans BRAT, choisir **Ajouter une extension bêta** et coller l'adresse de ce dépôt
3. Activer **Date de mise à jour** dans les extensions communautaires
